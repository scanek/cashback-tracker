# 💳 Cashback Hub (Кэшбэк Трекер)

> ❤️ **Сделано Александром Щеголевым для своей любимой жены Светик**

Мобильное приложение (React Native / Expo + TypeScript) для агрегации и отслеживания кэшбэков со всех банковских карт на каждый месяц.

---

## ✨ Основные возможности

1. 📊 **Дашборд месяца**:
   - Наглядный список всех активных банков (Т-Банк / Тинькофф, СберБанк, Альфа-Банк, ВТБ, Яндекс Пэй, Ozon Банк, Газпромбанк и др.).
   - Отображение выбранных категорий, процентов (%) и лимитов/условий на выбранный месяц.
   - Быстрое переключение между месяцами и годами.

2. 📸 **AI-Сканер скриншотов (Gemini Vision)**:
   - Загрузка скриншота экрана выбора кэшбэка в приложении любого банка.
   - Искусственный интеллект автоматически определяет банк, месяц, список категорий и проценты.
   - Окно проверки: возможность в один клик подправить категорию или процент перед сохранением.
   - Режим демо-распознавания для мгновенного теста без API ключа.

3. 🎯 **Умный помощник «Чем платить?»**:
   - Мгновенный поиск выгодной карты по магазину или категории (например: *«Пятёрочка»*, *«АЗС»*, *«Вкусно и точка»*, *«Аптека»*, *«Lamoda»*).
   - Интеллектуальный синонимический подбор (понимает бренды и категории РФ).
   - Ранжирование карт от самой выгодной (🏆 1 место) до базовой (1% на всё).

4. ✍️ **Ручной ввод и управление**:
   - Быстрое добавление и редактирование категорий вручную с быстрыми пресетами (1%, 3%, 5%, 7%, 10%, 15%, 20% или свой %).
   - Включение/отключение банков и добавление собственных карт.

5. 🔔 **Напоминания 1-го числа**:
   - Локальные пуш-уведомления в начале каждого месяца с напоминанием выбрать кэшбэк.

6. 🔒 **Приватность и надежность**:
   - Все данные хранятся исключительно локально на вашем устройстве (AsyncStorage).
   - Возможность экспорта и импорта резервной копии в JSON.

## 🚀 Как запустить приложение

### 1. Запуск на смартфоне (iOS / Android)

1. Установите бесплатное приложение **Expo Go** из [App Store](https://apps.apple.com/app/expo-go/id982107779) (iOS) или [Google Play](https://play.google.com/store/apps/details?id=host.exp.exponent) (Android).
2. В терминале в папке проекта выполните:
   ```bash
   npm start
   ```
3. Отсканируйте появившийся в терминале QR-код:
   - На **Android**: через приложение Expo Go (кнопка *Scan QR code*).
   - На **iOS**: через стандартное приложение *Камера*.

### 2. Запуск в браузере (Web-предпросмотр)

```bash
npm run web
```

## 🔑 Настройка Gemini Vision AI

Для реального распознавания скриншотов:
1. Получите бесплатный API ключ в [Google AI Studio](https://aistudio.google.com/app/apikey).
2. В приложении перейдите во вкладку **Настройки** -> вставьте ключ в поле **Google Gemini API** -> нажмите **Сохранить ключ**.
