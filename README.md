# 💳 Мои Кэшбеки (Cashback Tracker)

> ❤️ **Сделано Александром Щеголевым для своей любимой жены Светик**  
> **Версия**: `1.6.0` | **Платформы**: Android (APK + Виджет) / Web (Docker) / iOS

Современное интеллектуальное приложение и интерактивный виджет на базе **React Native (Expo SDK 54)** и **TypeScript** для легкого отслеживания, сканирования через AI и выбора самых выгодных категорий кэшбэка со всех банковских карт каждый месяц.

---

## ✨ Ключевые возможности

### 🔒 Безопасность: Защита PIN-кодом и защита от перебора (Brute-Force)
- **Экран блокировки PIN-кодом**: Надежная защита ваших карт и настроек при открытии сайта или приложения.
- **Интеллектуальная защита от подбора (Rate Limiting)**:
  - 3 неверных попытки ➔ блокировка ввода на **30 секунд** с таймером.
  - 5 неверных попыток ➔ блокировка на **5 минут**.
  - 10 неверных попыток ➔ блокировка на **30 минут**.
  - Автоматическая защита от брутфорса на уровне сервера (`HTTP 429 Too Many Requests` по IP).
- **Быстрый доступ для семьи**: Ввод PIN один раз сохраняет безопасную сессию на доверенном устройстве.

### 1. 👥 Персонализированный семейный доступ и раздельный просмотр
- **Настраиваемое имя партнера**: В Настройках можно задать собственное имя (например, *«Карты Саши»*, *«Саша»*, *«Светик»*, *«Жена»*).
- **Вкладки владельцев**: Удобное переключение между:
  - 👤 **«Мои»** — ваши персональные банковские карты.
  - ❤️ **«Карты партнера (Саша / Светик)»** — категории карт партнера / семьи (сохраняются отдельно, не перезаписывая ваши личные карты).
  - ✨ **«Все»** — единый каталог всех карт семьи.
- **Умный импорт**: При вставке кода или загрузке `.json` файла можно выбрать сохранение в свои карты или в карты партнера.
- **Адаптивный дизайн**: Карточки банков и переключатели идеально оптимизированы под любые размеры экранов смартфонов без разъезжания.

### 2. 📸 Интеллектуальный AI-сканер скриншотов
- Распознавание скриншотов через Google Gemini Vision с автоматической привязкой к **текущему реальному году (2026)** без необходимости вручную менять год.

### 3. 🎯 Умный помощник «Чем платить?» (Все кэшбэки месяца)
- **Полный каталог всех кэшбэков**: Выводит абсолютно все активные категории всех банков на выбранный месяц (от 50% до базовых 1%), отсортированные по размеру выгоды.
- **Интеллектуальный поиск и синонимы**:
  - *«Топливо в Городе»* (Т-Банк / Тинькофф) автоматически находится при поиске «Бензин», «АЗС», «Заправка», «Лукойл», «Газпромнефть», «Роснефть», «Тебойл» и др.
  - Поиск по брендам (*«Пятёрочка»*, *«Вкусно и точка»*, *«Аптека Апрель»*, *«Lamoda»*, *«Яндекс Маркет»*).
- **Фильтры по банкам и владельцам**: Фильтруйте рекомендации по конкретным банкам или по своим / партнерским картам.

### 3. 📱 Интерактивный виджет для рабочего стола Android (Home Screen Widget)
- **Все банки и категории на экране телефона**: Отображает полный список активных банков (Т-Банк, Ozon, Альфа, Сбер, Яндекс, ВТБ и др.) с цветными бейджами и процентами.
- **Интерактивный переключатель месяцев (`◀` `Август 2026` `▶`)**: Переключайте и просматривайте категории за любой месяц прямо на рабочем столе смартфона без входа в приложение.
- **3 темы оформления виджета**:
  - 🌙 **Темная (Dark)** — глубокий темный фон `#0F172A` с четким текстом.
  - ☀️ **Светлая (Light)** — контрастный белый фон `#FFFFFF` с фирменными бейджами.
  - 💎 **Прозрачная (Стекло / Glass)** — полупрозрачный фон с мягкой обводкой, идеально гармонирует с любыми обоями рабочего стола.
  - *Быстрое переключение темы виджета*: в 1 клик по иконке темы на самом виджете или в Настройках приложения.
- **Динамический размер (Resize)**: Возможность растягивать виджет на рабочем столе на любую высоту (4x2, 4x3, 4x4).
- **Мгновенная синхронизация**: При любом добавлении, AI-сканировании или импорте виджет на рабочем столе моментально обновляется.

### 4. ⚙️ Управление, шеринг, экспорт и резервное копирование
- 📸 **Распознать скриншот (Google Gemini AI Vision)**: Быстрый переход к умному сканеру категорий.
- 🚀 **Супер-компактный код `CBHUB2:...`**: Благодаря алгоритму сжатия **LZ-String** код весит всего **~120–180 символов** (вместо 5000+). Он гарантированно помещается в одно короткое сообщение Telegram / WhatsApp / SMS и никогда не обрезается.
- 📎 **Настоящий файл `.json` на Android**: Нажатие на **«Скачать / Отправить файл .json»** создает файл и открывает системное меню Android «Поделиться» для отправки в Telegram, WhatsApp или сохранения в память.
- 📥 **Создание и восстановление полного бэкапа**:
  - Кнопка **«Создать бэкап»** выгружает полный JSON-архив со всеми банками и историей кэшбэка.
  - Кнопка **«Восстановить»** позволяет загрузить сохраненный `.json` бэкап на любом устройстве в 1 клик!
- 📅 **Выбор месяца**: Возможность выбрать любой месяц для экспорта или шеринга.

### 5. 🎨 Темы оформления приложения
- Полноценная поддержка Dark & Light режимов интерфейса с быстрым переключателем (☀️ / 🌙) в шапке и настройками.

### 6. 🐳 Готовая веб-версия в Docker
- Развертывание на домашнем сервере (NAS, OpenMediaVault, VPS, Raspberry Pi) за 1 минуту через легкий Nginx-контейнер.

## 🤖 Бесплатная автоматическая сборка Android .APK (GitHub Actions)

Вам больше **не нужны платные тарифы и лимиты Expo EAS** — проект оснащен настроенным CI/CD пайплайном **GitHub Actions**, который бесплатно и без ограничений компилирует готовый автономный `.apk` файл на облачных серверах GitHub!

### 📥 Способ 1: Скачать готовый APK со страницы релизов
1. Перейдите в раздел **[GitHub Releases](https://github.com/scanek/cashback-tracker/releases)**.
2. Скачайте файл `Мои_Кэшбеки.apk` последней версии на смартфон.
3. Откройте скачанный файл на телефоне и нажмите **«Установить»**.

### 🚀 Способ 2: Запустить новую сборку APK вручную
1. **В браузере**:
   - Перейдите во вкладку **[Actions](https://github.com/scanek/cashback-tracker/actions)** в репозитории.
   - Слева выберите workflow **«Build Android APK»**.
   - Нажмите кнопку **«Run workflow»** ➔ выберите ветку `master` ➔ нажмите зеленую кнопку **«Run workflow»**.
   - Через 3–4 минуты сборка завершится, и готовый APK появится во вкладке артефактов и релизов!
2. **Через терминал**:
   ```powershell
   gh workflow run "Build Android APK"
   ```

## 📲 Как добавить виджет на рабочий стол телефона:

1. Зажмите свободное место на домашнем экране телефона (1–2 секунды).
2. Выберите пункт **«Виджеты»** (Widgets).
3. Найдите приложение **«Мои Кэшбеки»**.
4. Перетащите виджет на рабочий стол и растяните до желаемого размера (например, 4x2, 4x3 или во всю ширину).
5. При желании переключайте тему виджета (`🌙` / `☀️` / `💎`) прямо нажатием на иконку темы на самом виджете.

## 🔑 Настройка Gemini Vision AI и ссылки на API-ключи

В проект **уже встроен рабочий ключ Gemini API по умолчанию**, сканер и распознавание работают сразу «из коробки»!

Если вы хотите использовать собственный персональный ключ:

1. 🔗 **Где получить бесплатный ключ**:
   - Перейдите в [Google AI Studio: Get API Key](https://aistudio.google.com/app/apikey).
   - Войдите в Google-аккаунт и нажмите **«Create API Key»**.
   - Скопируйте созданный ключ.

2. ⚙️ **Как применить ключ в приложении**:
   - Откройте вкладку **«Настройки»** в приложении.
   - Вставьте ключ в поле **Google Gemini API**.
   - Нажмите **«Проверить AI»** для теста подключения.
   - Нажмите **«Сохранить»**.

## 🚀 Варианты запуска проекта

### 1. Запуск на смартфоне через Expo Go (для разработки)

1. Установите **Expo Go** из [Google Play](https://play.google.com/store/apps/details?id=host.exp.exponent) или [App Store](https://apps.apple.com/app/expo-go/id982107779).
2. В терминале запустите:
   ```powershell
   npm start
   ```
3. Отсканируйте QR-код в терминале.

### 2. Запуск локальной веб-версии в браузере

```powershell
npm run web
```
Приложение откроется по адресу `http://localhost:8081`.

### 3. Развертывание в Docker (Готовые образы GHCR + Автообновление) 🐳

Проект автоматически собирается в облаке GitHub Actions и публикуется в **GitHub Container Registry (`ghcr.io`)**. Вам не нужно компилировать проект на сервере — контейнеры запускаются за несколько секунд!

#### Быстрый запуск в 1 команду:

1. **Склонируйте репозиторий на сервер (NAS / Linux / VPS):**
   ```bash
   git clone https://github.com/scanek/cashback-tracker.git
   cd cashback-tracker
   ```

2. **Запустите контейнеры:**
   ```bash
   PORT=8085 docker compose up -d
   ```
   *Docker скачает готовые легковесные образы `ghcr.io/scanek/cashback-tracker-web` и `ghcr.io/scanek/cashback-tracker-server`, а также сервис автообновления `watchtower`.*

3. **Откройте веб-приложение в браузере:**
   👉 `http://IP_ВАШЕГО_СЕРВЕРА:8085`

---

#### 🔄 Автоматическое обновление приложения (Watchtower):
В состав `docker-compose.yml` уже входит контейнер **Watchtower**. Он каждые 5 минут проверяет наличие новых версий образов на GitHub и **автоматически бесшовно обновляет веб-версию и сервер**, удаляя старые образы и освобождая место на диске.

Если вы хотите обновить контейнеры вручную:
```bash
docker compose pull
docker compose up -d
```

---

#### ⚙️ Настройка собственного порта и Gemini API:
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```
В файле `.env` можно указать:
- `PORT=8085` — порт для открытия веб-интерфейса в браузере.
- `GEMINI_API_KEY=AIzaSy...` — ваш личный ключ Google Gemini (опционально, для работы AI-сканера чеков/скриншотов).

## 🛠 Стек технологий

- **Фреймворк**: React Native 0.81 / Expo SDK 54 (TypeScript)
- **CI/CD Автосборка APK**: GitHub Actions (Ubuntu / Gradle / Android SDK)
- **Виджет Android**: `react-native-android-widget` (AppWidget RemoteViews)
- **Файловая система и шеринг**: `expo-file-system`, `expo-sharing`, `expo-document-picker`
- **Сжатие данных**: `lz-string` (LZ-based compression)
- **Искусственный интеллект**: Google Gemini 3.6 Flash / 2.5 Flash Vision API
- **Хранилище**: `AsyncStorage` (100% локальное хранение данных на устройстве)
- **Иконки**: Lucide Icons (`lucide-react-native`)
- **Веб-сервер Docker**: Nginx Alpine с Gzip-оптимизацией и SPA-роутингом
