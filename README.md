# 💳 Мои Кэшбеки (Cashback Tracker)

> ❤️ **Сделано Александром Щеголевым для своей любимой жены Светик**  
> **Версия**: `1.8.5` | **Платформа**: Android (Автономный APK + Виджет) / iOS / Web

Современное автономное мобильное приложение (**Local-First**) и интерактивный виджет для рабочего стола на базе **React Native (Expo SDK 54)** и **TypeScript**. Помогает мгновенно определить, какой банковской картой выгоднее всего расплатиться на кассе супермаркета, АЗС, в ресторане или аптеке, а также быстро сканировать скриншоты категорий через Google Gemini AI.

---

## 🌟 Главная философия: 100% автономность (Local-First)

Приложение **полностью независимо от внешних и домашних серверов**:
* **Мгновенный запуск 0 мс**: Все данные хранятся локально в безопасном хранилище вашего телефона (`AsyncStorage` + `SecureStore`).
* **Работает без интернета**: В подвальных магазинах, на подземных парковках и в роуминге приложение открывается сразу и всегда готово подсказать карту.
* **Никаких серверов и Docker**: Больше не нужно настраивать серверы, следить за контейнерами, пробрасывать порты или переживать за домашний интернет.

## ✨ Ключевые возможности

### 1. 🎯 Умный советник «Чем платить?»
* **Моментальный выбор лучшей карты**: Сортирует абсолютно все категории всех ваших банков от максимального процента кэшбэка (например, 50% или 10%) до базового 1%.
* **Поиск по брендам и синонимам**:
  * Введите *«бензин»* или *«заправка»* ➔ автоматически найдёт категории *«АЗС»*, *«Топливо»*, *«Лукойл»*, *«Газпромнефть»*.
  * Введите *«продукты»* ➔ мгновенно найдёт *«Супермаркеты»*, *«Пятёрочка»*, *«Магнит»*, *«Купер»*.
  * Ищет по любым популярным магазинам: *«Аптека Апрель»*, *«Яндекс Маркет»*, *«Вкусно и точка»*, *«DNS»* и др.
* **4 удобных режима отображения**: Компактный список, фокусная карточка (Spotlight), группировка по банкам или адаптивная сетка (Grid).

### 2. 📱 Интерактивный виджет для рабочего стола Android
* **Категории прямо на экране телефона**: Полный список банков с цветными карточками, процентами и лимитами без необходимости заходить в приложение.
* **Интерактивный выбор месяца (`◀` `Октябрь 2026` `▶`)**: Листайте категории прямо с виджета.
* **3 темы оформления виджета**:
  * 🌙 **Тёмная (Dark)** — глубокий фон `#0F172A` с контрастными бейджами.
  * ☀️ **Светлая (Light)** — кристально белый фон.
  * 💎 **Прозрачная (Стекло / Glass)** — полупрозрачный фон, органично сливающийся с любыми обоями.
* **Мгновенное обновление**: При любом изменении или добавлении категорий виджет обновляется автоматически.

### 3. 👥 Семейный доступ и обмен картами (раз в месяц)
* **Раздельный просмотр**:
  * 👤 **«Мои»** — ваши личные карты.
  * ❤️ **«Карты партнёра»** — карты супруга/супруги (название настраивается: *«Карты Саши»*, *«Светик»*, *«Жена»*).
  * 👥 **«Все»** — объединённый каталог всей семьи.
* **Обмен в 1 клик без серверов**:
  1. 1-го числа месяца муж нажимает **«Поделиться картами»** ➔ формируется сверхкомпактный код `CBHUB2:...` и открывается меню отправки в Telegram/WhatsApp.
  2. Жена нажимает **«Импортировать»** ➔ вставляет код или открывает полученный файл ➔ приложение за 2 секунды сохраняет категории в её телефоне!

### 4. 📸 Прямое распознавание скриншотов через Google Gemini Vision
* Быстрое распознавание текста категорий и процентов прямо со скриншотов банковских приложений (Т-Банк, Сбер, Альфа, ВТБ, Ozon, Яндекс Пэй, Газпромбанк и др.).
* **Прямой вызов Google AI Studio**: Запросы идут с телефона напрямую в Google Gemini API по безопасному заголовку `x-goog-api-key`, минуя любых сторонних посредников.
* Автоматический fallback: приоритетная модель `gemini-2.0-flash` с автоматическим переключением на `gemini-1.5-flash`.

### 5. 🔒 Безопасность и защита PIN-кодом
* Быстрая блокировка приложения цифровым 4-значным PIN-кодом с хэшированием PBKDF2/SHA-256 и криптографической солью.
* Интеллектуальный Rate Limiting при неверном вводе (таймаут от 30 секунд до 30 минут).

### 6. 💾 Резервное копирование и экспорт
* Полный экспорт всех ваших карт и настроек в JSON-файл в 1 клик.
* Моментальное восстановление из файла бэкапа на любом новом устройстве.

## 📲 Установка готового Android приложения (.APK)

В репозитории настроен автоматический CI/CD на базе **GitHub Actions**, который бесплатно и чисто компилирует релизный standalone APK:

1. Перейдите в раздел **[GitHub Releases](https://github.com/scanek/cashback-tracker/releases)**.
2. Скачайте `Мои_Кэшбеки.apk` актуальной версии.
3. Откройте файл на Android-устройстве и подтвердите установку.

---

## 📱 Как включить виджет на Android

1. Зажмите свободное место на домашнем экране телефона (1–2 секунды).
2. Выберите пункт **«Виджеты»** (Widgets).
3. Найдите в списке **«Мои Кэшбеки»**.
4. Перетащите виджет на экран и растяните до желаемого размера (например, 4x2, 4x3 или во всю ширину).
5. Тему виджета можно переключать прямо нажатием на иконку темы на самом виджете.

---

## 🔑 Подключение собственного ключа Google Gemini AI

Приложение готово работать с вашим личным бесплатным ключом Google AI Studio:

1. Перейдите в [Google AI Studio](https://aistudio.google.com/app/apikey) и нажмите **«Create API Key»**.
2. В приложении перейдите во вкладку **«Настройки»** ➔ раздел **Google Gemini AI**.
3. Вставьте ключ и нажмите **«Проверить AI»**, затем **«Сохранить»**.

## 🛠 Запуск для разработки

### Требования
* Node.js 20+
* npm

### Установка зависимостей
```bash
npm install --legacy-peer-deps
```

### Запуск в режиме разработки
```bash
# Запуск Metro bundler для телефона (Expo Go)
npm start

# Локальный веб-просмотр в браузере
npm run web
```

### Локальная сборка release APK (на машине с Android SDK):
```powershell
npm run build:apk:local
```
или просто отправьте коммит с тегом `v1.x.x` в репозиторий — GitHub Actions соберёт релизный APK в облаке автоматически.

## 📦 Стек технологий

* **Фреймворк**: React Native 0.81 / Expo SDK 54 (TypeScript)
* **Архитектура**: Local-First (100% автономное клиентское приложение)
* **Хранилище**: `@react-native-async-storage/async-storage` + Expo SecureStore
* **Виджет**: `react-native-android-widget`
* **AI Vision**: Google Gemini 2.0 Flash / 1.5 Flash (Google AI Studio API)
* **Сжатие для шеринга**: `lz-string` (сверхкомпактные коды обмена)
* **Иконки**: `lucide-react-native`
* **CI/CD**: GitHub Actions (Ubuntu / OpenJDK 17 / Android Command-line Tools / Gradle)
