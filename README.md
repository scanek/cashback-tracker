# 💳 Cashback Hub (Кэшбэк Трекер)

> ❤️ **Сделано Александром Щеголевым для своей любимой жены Светик**

Современное кроссплатформенное приложение (**Android / iOS / Web / Docker**) на базе React Native (Expo) и TypeScript для умного отслеживания и выбора самых выгодных категорий кэшбэка со всех банковских карт каждый месяц.

---

## ✨ Основные возможности

1. 📊 **Дашборд месяца**:
   - Наглядный список всех активных банков (Т-Банк / Тинькофф, СберБанк, Альфа-Банк, ВТБ, Яндекс Пэй, Ozon Банк, Газпромбанк и др.).
   - Отображение категорий, процентов (%) и лимитов/условий на выбранный месяц.
   - Быстрое переключение между месяцами и годами в один клик.

2. 📸 **AI-Сканер скриншотов (Gemini 3.6 Flash Vision)**:
   - Загрузите скриншот экрана выбора кэшбэка в банковском приложении.
   - Нейросеть автоматически определяет банк, месяц, список категорий и проценты.
   - Интерактивное окно подтверждения: возможность сменить банк, месяц или отредактировать категории.

3. 🎯 **Умный помощник «Чем платить?»**:
   - Мгновенный поиск выгодной карты по магазину или категории (*«Пятёрочка»*, *«АЗС / Лукойл»*, *«Вкусно и точка»*, *«Аптека»*, *«Lamoda»*, *«Яндекс Маркет»*).
   - Интеллектуальный синонимический подбор брендов и категорий РФ.
   - Ранжирование карт от самой выгодной (🏆 1 место) до базовой (1% на всё).

4. 📲 **Обмен кэшбэком (Шеринг и Импорт)**:
   - Кнопка **«Поделиться»** на карточке банка или за весь месяц.
   - Формирует аккуратный текст для Telegram/WhatsApp с мини-кодом `CBHUB:...`.
   - Получатель копирует сообщение, нажимает **«Импортировать кэшбэк»** и мгновенно переносит категории себе.

5. 🐳 **Веб-версия в Docker**:
   - Запуск на домашнем сервере (NAS, VPS, Raspberry Pi) через легкий Nginx-контейнер.

6. 🔔 **Напоминания 1-го числа**:
   - Напоминание в начале каждого месяца зайти в приложения банков и выбрать кэшбэк.

## 📱 Сборка Android .APK (Подробная инструкция)

Приложение собирается в автономный `.apk` файл через облачный сервис **EAS Build (Expo Application Services)**.

### 📋 Предварительные требования:
1. Зарегистрируйте бесплатный аккаунт на [expo.dev](https://expo.dev/signup).
2. На компьютере должен быть установлен **Node.js** (версии 18 или 20+).

### 🚀 Пошаговый процесс сборки:

1. **Откройте терминал в папке проекта:**
   ```powershell
   cd cashback-tracker
   ```

2. **Авторизуйтесь в EAS (если еще не авторизованы):**
   ```powershell
   npx eas-cli login
   ```
   *(Введите ваш Email и пароль от аккаунта Expo)*.

3. **Запустите сборку автономного .APK:**
   ```powershell
   npm run build:apk
   ```
   *(Эта команда запускает `npx eas-cli build -p android --profile preview`)*.

4. **Получение готового приложения:**
   - Сборка начнется на облачном сервере Expo (занимает ~3–5 минут).
   - В терминале появится ссылка на отслеживание сборки в браузере.
   - По завершении в терминале и на странице сборки отобразится **QR-код и прямая ссылка** для скачивания файла `CashbackHub.apk`.
   - Наведите камеру вашего смартфона (например, **Samsung Galaxy S25 FE**) на QR-код, скачайте `.apk` и установите его!

## 🔑 Настройка Gemini Vision AI и ссылки на API-ключи

В проект **уже встроен рабочий ключ Gemini API по умолчанию**, поэтому сканер работает сразу после установки!

Если вы хотите подключить свой личный ключ:

1. 🔗 **Где получить бесплатный ключ**:
   - Перейдите в [Google AI Studio: Get API Key](https://aistudio.google.com/app/apikey).
   - Войдите с помощью аккаунта Google и нажмите **«Create API Key»**.
   - Скопируйте созданный ключ (строка вида `AIzaSy...` или `AQ...`).

2. ⚙️ **Как применить ключ в приложении**:
   - Откройте вкладку **«Настройки»** в приложении.
   - Вставьте ваш ключ в поле **Google Gemini API**.
   - Нажмите кнопку **«Проверить AI»** — приложение мгновенно протестирует подключение к Google и покажет выбранную модель.
   - Нажмите **«Сохранить»**.

## 🚀 Варианты запуска проекта

### 1. Запуск на смартфоне через Expo Go (для разработки)

1. Установите приложение **Expo Go** из [Google Play](https://play.google.com/store/apps/details?id=host.exp.exponent) (Android) или [App Store](https://apps.apple.com/app/expo-go/id982107779) (iOS).
2. В терминале запустите:
   ```powershell
   npm start
   ```
3. Отсканируйте QR-код камерой телефона или через Expo Go.

### 2. Запуск веб-версии локально в браузере

```powershell
npm run web
```
Приложение откроется по адресу `http://localhost:8081`.

### 3. Запуск веб-версии в Docker (на удаленном сервере / NAS) 🐳

1. **Склонируйте репозиторий на сервер:**
   ```bash
   git clone https://github.com/scanek/cashback-tracker.git
   cd cashback-tracker
   ```

2. **Запустите Docker Compose:**
   ```bash
   PORT=8085 docker compose up -d --build
   ```

3. **Откройте в браузере:**
   👉 `http://IP_ВАШЕГО_СЕРВЕРА:8085`

## 🛠 Стек технологий

- **Фреймворк**: React Native 0.81 / Expo SDK 54 (TypeScript)
- **Искусственный интеллект**: Google Gemini 3.6 Flash / 2.5 Flash Vision API
- **Хранилище данных**: AsyncStorage (100% локально на устройстве, без внешних серверов)
- **Иконки**: Lucide Icons (`lucide-react-native`)
- **Веб-сервер Docker**: Nginx Alpine с Gzip-сжатием и SPA-роутингом
- **Сборка APK**: EAS Build Cloud CLI
